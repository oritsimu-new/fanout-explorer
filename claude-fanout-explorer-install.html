Claude Fanout Explorer

Version 2026-09-22, released 22 September 2026. What changed

A bookmarklet that shows every web search Claude runs behind the scenes for a chat and every page it opens, live as it answers or on a saved chat, with the pages each search got back and which of them were cited. Read-only.

What it shows

Live and saved chats. On a new chat each search appears as Claude runs it, one query at a time, filling while the answer is written. On a chat from your history it shows at once. For every search and every page Claude opens it gives you the query, the pages that came back and which of them were cited, exact per query.

Version 2026-09-22, released 22 September 2026

Lighter on the rate limit. The reader no longer keeps re-reading a chat that has a stopped or regenerated answer in its history, and it never reads from a background tab. Drag the panel by its toolbar to move it, and pull the bottom right corner to resize it. It opens at the top right, which is awkward on a magnified screen or a narrow window, and where you put it is remembered for next time. Double-click the toolbar to send it back to where it started. Escape closes the panel, the toolbar with the Close button stays pinned to the top while you scroll and the panel can no longer run past the edge of the screen. The panel also shows its build date next to the title, so a stale bookmark is easy to spot.

Which version are you running? Click your bookmark on a chat and look next to the title at the top of the panel. It shows the build date, like v2026-09-22. No date there means you are on a build older than 2026-09-22.

Getting this build. The short version fetches the newest code from GitHub each time you click it, so it picks this up on its own within the hour. The standalone version has all of its code inside the bookmark and never changes by itself: Drag or paste it again from this page to move to this build. Opening this page is not enough, the bookmark itself has to be replaced.

If clicking the bookmark does nothing

  • Right-click the bookmark, choose Edit and check the URL starts with javascript:. If it is empty, short, or the address of this page, the drag did not take: Use the copy button and paste the code as the bookmark URL.
  • On a company-managed browser, bookmarklets are often blocked by policy. Open chrome://policy or edge://policy and look for javascript://* under URLBlocklist. A personal browser profile gets around it.
  • Console route, if bookmarks are blocked but DevTools is not: On claude.ai, press F12 or Ctrl+Shift+I, open the Console tab, paste the standalone code and press Enter. Chrome asks you to type allow pasting the first time.
  • It has to be a chat page on claude.ai, logged in, in the browser where you installed it. The desktop apps have no bookmarks bar.

Use

  1. Live: Open a new chat on claude.ai in Chrome, click the bookmark, send your prompt. Searches appear as Claude runs them.
  2. Saved chat: Open the chat, click the bookmark. Chats you have read before show at once from a saved copy in your browser.
  3. The prompt shows above the table. Click + on any line to see the pages it got back, ticks mark the cited ones. Expand all opens every line for a screenshot.
  4. Click a column header to sort. Download CSV is one row per search, Download sources CSV adds one row per page underneath each search.
  5. The Index tab explains every column, the Types tab the tools Claude uses. If claude.ai rate limits you (429), the panel keeps what it has and retries later.
